# 設計書：コホート再訪率カードのインサイト（2026-09-07、改訂版）

ユーザー承認済み。「リピーター・コホート再訪率」カードの表の上に、既存と同じ形式（`InsightGroup[]` → `renderInsightGroups`）でインサイトを出す。対象は全期間・参加日ベース・phoneHash で同一人物判定。比較に必要な人数がなければその行／グループを出さない（無理に断定しない）。

> 改訂の経緯: 初版はグループ1・2で「まだ13ヶ月の観測窓が完了していない人」も母数に含めており、右側打ち切り（right-censoring）——まだ再訪する余地が残っている人を「再訪なし」に数えてしまう——が起きていた。またグループ3・4のhint閾値やグループ4のプールサイズ下限がノイズを有意な差として誤認しやすい値だった。本改訂でこれらを是正する。

## 集計（`src/metrics/cohortInsights.ts`）
`buildCohortInsights(input: { all: HistoryRecord[]; cohorts: CohortRow[]; today: string /* YYYY-MM-DD */ }): InsightGroup[]`

共通:
- `first = firstVisitMap(all)`（phoneHash→初回参加日）は関数内で **1回だけ**計算し、人物集計（`buildPeople`）とグループ5の両方で使い回す（重複呼び出しをしない）。
- phoneHash 空は除外。`todayYm = ymOf(today)`。
- 人ごとの「再訪」は **初回月より後の月**の参加（`monthsBetween(firstYm, ym) >= 1`）。同じ月内の2回目は再訪に数えない（コホート表の定義と統一）。
- `pct(a,b) = Math.round(a/b*100)`。
- **完了窓ルール**: 「初回月から13ヶ月経過している」＝`monthsBetween(firstYm, todayYm) >= 13`。グループ1・2・3・4はすべてこのルールで「まだ観測が終わっていない人／コホート」を除外する（右側打ち切り対策）。
- **最大剰余法（largest remainder method）**: 複数バケットの割合（%）を合計がちょうど100になるよう丸める方法。各バケットの生の割合を切り捨てた後、100に足りない分（remainder）を「切り捨てで失った端数（小数部分）が大きい順」に1ptずつ配る。端数が同着の場合は、バケットの並び順で **先に出てくるバケットを優先**する（tie-break: earlier bucket wins）。

### 1. リピートの全体像（title: 'リピートの全体像'）
- 対象人物は **完了窓の人だけ**（`monthsBetween(firstYm, todayYm) >= 13`）。N = そのうち初参加者のユニーク人数、M = そのうち再訪した人数。
- text: `13ヶ月以上前に初参加した ${N}人のうち、2回目以降も来た人 ${M}人（${pct}%）`
- hint: pct ≥ 20 → `→ 5人に1人以上が戻っている`／10 ≤ pct < 20 → `→ 10人に1〜2人が戻る水準`／pct < 10 → `→ 戻る人は10人に1人未満`
- N < 20 ならグループごと省略。

### 2. 戻ってくるタイミング（title: '戻ってくるタイミング'）
- 対象人物はグループ1と同じ完了窓の人（`monthsBetween(firstYm, todayYm) >= 13`）のうち再訪した人。
- 各人について gap = 初回月から **最初の再訪月** までの月数（上限なし）。バケット: 1〜3 = `3ヶ月以内`、11〜13 = `翌年の同時期`、それ以外 = `それ以外`。
- 各バケットの割合は M に対して**最大剰余法**で丸め、3バケットの合計が必ず100%になるようにする（同着は「3ヶ月以内→翌年の同時期→それ以外」の順で先のバケットが繰り上がる）。
- text: `再訪した人の内訳: 3ヶ月以内 ${a}%／翌年の同時期（11〜13ヶ月後） ${b}%／それ以外 ${c}%`
- hint: a > b → `→ 同じシーズン中に戻る人が多い`／b > a → `→ 翌シーズンに戻る傾向`／a === b → hint なし
- M < 10 なら省略。

### 3. 年ごとの定着率（title: '年ごとの定着率（1年後に戻った割合）'）
- 初参加年 Y ごと（全人物が対象、完了窓フィルタは年単位の条件で別途かける）: N_Y = 初参加者数、R_Y = そのうち初回月から 11〜13 ヶ月後に参加した人数（ユニーク）。
- 対象年の条件: `monthsBetween(\`${Y}-12\`, todayYm) >= 13`（その年の全コホートの13ヶ月窓が完了）かつ N_Y ≥ 20。
- text: 対象年を昇順に `${Y}年 ${pct}%` を `／` で連結（例 `2023年 20%／2024年 25%`）。
- hint: 対象年が2つ以上のとき、末尾2年の差 d（ポイント）: **d ≥ 5** → `→ 定着率は上がっている`／**d ≤ -5** → `→ 定着率は下がっている`／それ以外 → `→ 定着率はほぼ横ばい`。1年しかなければ hint なし。（旧版は ±2pt。ノイズを有意な変化と誤認しないよう ±5pt に引き上げ）
- 対象年が0ならグループ省略。

### 4. 初回月による戻りやすさ（title: '初回月による戻りやすさ'）
- `cohorts` のうち `monthsBetween(cohort, todayYm) >= 13` の行を **暦月（MM）でプール**: size_MM = Σsize、year_MM = ΣyearLater（同月の複数年を合算）。
- **size_MM ≥ 40** の月だけ対象（旧版は10。プールサイズが小さいとノイズで極端な率になりやすいため引き上げ）。対象が2月未満ならグループ省略。
- rate_MM = pct(year_MM, size_MM)。最大の月 hi と最小の月 lo。
- **省略ガード**: 対象月がすべて同じ丸め後の割合の場合（`hi.mm === lo.mm`、比較材料がない状態）はグループごと省略する。
- text: `初回が${hi}月の人は翌年 ${rate_hi}%、${lo}月の人は ${rate_lo}%（1年後に戻った割合）`
- hint: **rate_hi − rate_lo < 5** → `→ 初回の時期による差は小さい`（旧版は3pt未満）／lo が 7 または 8 かつ hi がそれ以外 → `→ 繁忙期に初めて来た人ほど翌年に戻りにくい傾向`／それ以外 → `→ 初回の時期で翌年の戻りやすさに差がある`
- 月表記は先頭ゼロなし（`6月`）。

### 5. 直近の新規客（title: '直近の新規客'）
- thisYear = today の年。cur = 初回参加日が `${thisYear}-01-01`〜`today` の人数。prev = 初回参加日が `${thisYear-1}-01-01`〜`${thisYear-1}-${MM-DD of today}` の人数。
- diff（比較用の増減ポイント） = pct(cur−prev, prev)。表示は `src/metrics/insights.ts` の `signedPct(ratio)`（`export` 済み、`ratio = cur/prev`）を再利用し、`cohortInsights.ts` 側での複製はしない。
- text: `今年の初参加 ${cur}人（去年の同時期 ${prev}人、${signedPct(cur/prev)}）`。`signedPct` の表記規則: diff = 0 → `±0%`、正 → `+N%`、負 → `-N%`。
- hint: diff ≥ 10 → `→ 新規客は増えている`／diff ≤ −10 → `→ 新規客は減っている`／それ以外 → `→ 新規客はほぼ横ばい`
- prev < 20 なら省略。
